# Сон о Садко

Детская HTML5-игра по мотивам былины о Садко. Мальчик Елисей засыпает с книгой и попадает в мир Древнего Новгорода.

## Сюжет
Во сне Елисей встречает Странника, который просит помочь гусляру Садко. Тот попал в плен к Морскому царю, и его гусли вызывают страшную бурю. Елисей снаряжает ладью, плывёт на другой берег, разрушает заколдованные гусли и спасает Садко. В благодарность они вместе строят храм в Новгороде.

## Как играть
- Нажимай на иконки локаций, чтобы перемещаться по карте
- В уровнях «три в ряд» перетаскивай иконки, чтобы собрать 3+ одинаковых в ряд
- Каждый уровень — своя цель (бочки, струны, камни)
- 25 ходов на уровень, 5 жизней
- Собирай звёздочки-частицы при удачных комбинациях!
