# Сон о Садко

Детская HTML5-игра по мотивам былины о Садко. Мальчик Женя засыпает с книгой и попадает в мир Древнего Новгорода.

## Сюжет
Во сне Женя встречает Странника, который просит помочь гусляру Садко. Тот попал в плен к Морскому царю, и его гусли вызывают страшную бурю. Женя снаряжает ладью, плывёт на другой берег, разрушает заколдованные гусли и спасает Садко. В благодарность они вместе строят храм в Новгороде.

## Как играть
- Нажимай на иконки локаций, чтобы перемещаться по карте
- В уровнях «три в ряд» перетаскивай иконки, чтобы собрать 3+ одинаковых в ряд
- Каждый уровень — своя цель (припасы, гусли, стройблоки)
- 20 ходов на уровень, 5 жизней
